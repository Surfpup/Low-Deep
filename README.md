# Low-Deep
I created the game, Low Deep, 2D Metroidvania, In Development. Worlds 1–8 take about 2 hours or more to complete, but it may take longer if you spend more time fighting the bosses. The bosses are Ashling, the Bone Warden, the Hive Queen, the Cinder Dragon, the Big Troll, Dragula, Queen Spider Web, 2 Hive Queen, and Gargoyles.
